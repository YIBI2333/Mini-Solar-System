# Mini Solar System
一个简单的迷你太阳系 3D 网页模型。

## 运行

用浏览器运行打开 `Mini Solar System.html` 
（需联网或本地加载 Three.js）。

## 操作

- 拖拽鼠标：旋转视角
- 滚轮：缩放
- 点击天体：查看该天体的资料
- 底部滑条：调节公转速度

## 内容

- 太阳（表面纹理、辉光、耀斑粒子）
- 八大行星，各有独立贴图、轨道线和轴倾角，地球带云层
- 土星环（三层）、天王星环
- 卫星：月球、木星四颗伽利略卫星、土卫六
- 小行星带（1000 颗）与哈雷彗星（带彗尾）

## 说明

- 天体的大小和轨道距离为观感优化值，非真实比例。
- 想修改参数（行星大小、速度、小行星数量等），直接改 HTML 里的 `planetsData` 和对应变量即可。
